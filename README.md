# Amrita History Quiz

A simple Android quiz app about Amrita Vishwa Vidyapeetham, built with Java, XML layouts, and a local SQLite database.

## Features
- Amrita-inspired purple, blue, and gold home screen
- 15 multiple-choice questions
- Randomized question order
- Score and percentage result screen
- SQLite database for questions and saved scores
- Uses native Android Activity classes and no AppCompat dependency

## Android Studio settings
- Project name: `AmritaQuiz` (or `AmritaHistoryQuiz`)
- Package: `com.example.amritahistoryquiz`
- Language: Java
- Minimum SDK: API 24
- Gradle build files use Kotlin DSL

## Important setup notes
Open this repository in Android Studio and sync Gradle. If Android Studio cannot download Gradle, fix the network/proxy connection first. The Gradle wrapper JAR is not included in this repository, so if Android Studio reports a missing wrapper JAR, create an Empty Views Activity project in Android Studio and copy the files under `app/src/main` into it, keeping the Gradle wrapper generated by Android Studio.

## Build
Use **Build > Make Project**, then **Run** on an emulator or connected Android device. The source has not been compiled on the user's machine, so verify the build locally. Verify historical facts against official university sources before presenting.
