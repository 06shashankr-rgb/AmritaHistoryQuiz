# Amrita History Quiz

A simple Android quiz app about Amrita Vishwa Vidyapeetham, built with Java, XML layouts, and a local SQLite database.

## Features
- Home screen with Amrita-inspired purple, blue, and gold styling
- 15 multiple-choice questions
- Randomized question order
- Score and percentage screen
- SQLite database for quiz questions and saved scores

## Android Studio setup

This repository currently contains the app source files. To run it as a complete Android Studio project, create/open an Android Studio **Empty Views Activity** project with:
- App name: `AmritaHistoryQuiz`
- Package name: `com.example.amritahistoryquiz`
- Language: Java
- Minimum SDK: API 24 or higher

Then copy the files in this repository into the same paths in the new project. Keep the Gradle wrapper and Gradle configuration generated by Android Studio. The Java activities use AndroidX AppCompat; ensure your app module includes the AppCompat dependency, for example `implementation("androidx.appcompat:appcompat:1.7.0")` in `app/build.gradle.kts` if it is not already present.
